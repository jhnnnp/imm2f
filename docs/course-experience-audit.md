# 실제 방문 관점 코스 감사

이 감사의 질문은 "두 사람이 이 코스를 그대로 따라가도 시간을 잘 보냈다고 느낄까?"다. 장소가 존재하고 가까운지만으로 합격시키지 않는다. 사용자 목적, 장소별 선택 이유, 날짜와 체류 시간, 이동 부담, 실패 시 설명을 차례로 본다.

| 요청 | 따라가며 생기는 질문 | 이번 조치 | 여전히 확인할 것 |
| --- | --- | --- | --- |
| 공연을 보고 식사·카페 | 건물만 찾았는데 실제 공연이 있는가? 식사와 이동이 회차 전후에 들어가는가? | 방문일 공연 회차와 시간 배치를 검사한다. 공연장은 공연과 구분한다. | 좌석·예매·휴연은 공급자에서 재확인해야 한다. |
| 예쁜 카페 데이트 | 이 지점이 왜 예쁜가? 보드게임카페를 일반 카페로 오인하지 않았는가? | 정확한 지점의 공간 근거를 비교하고 교체 시 근거 없는 카페로 바꾸지 않는다. | 사진·영업 상태가 최신인지 독립 대조가 필요하다. |
| 음식 중심 데이트 | 이 음식이 실제 대표 메뉴인가? 식당 두 곳을 잇는 이유가 있는가? | 메뉴 근거와 경험 중복을 검사한다. | 실제 메뉴·가격·예약 가능 여부는 충분히 확보되지 않았다. |
| 당일치기 여행 | 차가 없는데 먼 명소를 짧은 이동으로 가정하지 않았는가? 도착·귀가 시간을 아는가? | 여행 규칙을 당일치기에도 적용하고 이동 수단별 시간 추정과 하루 경험 근거를 검사한다. | 실제 대중교통 경로와 출발지는 아직 모른다. |
| 1박2일·2박3일 | 첫날에 몰아 넣고 다른 날을 비우지 않았는가? 축제 날짜와 숙소 위치가 맞는가? | 각 날의 핵심 경험·근거·장소 수·축제 날짜와 수정 시 일차 보존을 검사한다. | 숙소·체크인·체크아웃·왕복 교통편은 코스 생성에 아직 포함되지 않는다. |

## 군산 1박2일 실측

2026-09-25에 카카오 검색 5종과 TourAPI 관광지 목록으로 75개 후보를 모았다. 기존 결정적 대안은 1일차 `군산근대화거리 → 싹싹브리또 근대역사거리점`, 2일차 `진포해양테마공원 → 카페196`을 선택했다. 동선은 짧았지만 네 장소의 선택 이유를 뒷받침하는 경험 근거가 0건이었다. 실제 여행자로서는 하루를 써서 이 조합을 방문할 이유가 부족하다.

초기 웹 조사에서는 후보의 지점 불일치와 일반적인 문장 때문에 핵심 경험 근거를 확보하지 못해, 약 32초 뒤 `여행 핵심 장소 근거 부족`을 반환했다. 원인을 추적하니 TourAPI 상세 요청에 현재 API가 거부하는 매개변수가 있었고, 루트 수준 오류 응답도 검출하지 못하고 있었다. 이를 수정하자 공식 관광지 본문이 들어왔다. 다시 실행한 결정적 대안은 `신흥동 일본식가옥 → 싹싹브리또`, `영화의 거리 → 오산상회`로 구성되며 네 장소의 근거가 모두 연결됐다. 다만 두 관광 경험의 주제가 근대거리 방문으로 겹치고 숙소·왕복 교통편은 반영되지 않아, 그대로 확정 여행으로 보기 어렵다. 실제 OpenAI 실행에서는 웹 조사와 코스 제안이 다시 실패해 이번에는 코스가 나오지 않았다. 외부 조사 성공률과 후보 순서에 따라 결과가 달라지는 문제도 남아 있다.

## 다음 품질 관문

이후 [품질 게이트](./date-trip-quality-gates.md)에 지원 범위와 군산·전주·경주 지역 실측을 분리해 기록했다. 관광지 공식 설명을 분산된 후보까지 조회하고, 날짜별 핵심 장소 근거·식사·경험 다양성 기준을 코스 선택에 반영했다. 첫날 도착·마지막 날 출발 시각이 명시된 경우 현지 시간창에 적용한다. 공연 회차도 여행의 각 날짜로 조회한다. 세 지역의 결정적 코스는 하드 제약을 통과했지만 장소별 근거는 4곳 중 2곳이었고 실제 교통·숙소 검증은 아직 없다.

1. 공식 관광지 본문을 제공자 ID와 연결하는 경로는 복구했다. 관광지 후보의 본문 품질을 일관되게 검사하고, 출처 근거가 없는 카카오 후보의 독립 조사 성공률을 높인다.
2. 도착·귀가 교통편과 숙소 기준점을 구조화한 뒤, 첫날·마지막 날의 실제 가용 시간과 숙소 전후 이동을 계산한다.
3. 실제 보행·대중교통·차량 경로와 가격·영업 정보를 연결한다. 현재 직선거리 기반 추정으로 환승·주차·도로 우회는 보증할 수 없다.
4. 당일치기, 1박2일, 2박3일의 지역·계절·날씨·수정 시나리오를 고정 평가 세트에 넣고, 실제 요청 실행과 사람의 블라인드 선호도로 코스 품질을 측정한다.
